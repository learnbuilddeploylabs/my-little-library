# 📖 My Little Library

Time to dust off those boxes of books and get to organizing!

---

## 📌 What This Program Does

- Lets you build and manage your personal book collection
- Stores book titles, author names, ISBNs, and page counts
- Allows you to view, add, edit, and remove books
- Automatically creates and maintains a local SQLite database
- Preserves your library between sessions

---

## 🛠 Requirements

- Python 3.12 or newer
- A terminal or command prompt
- No additional libraries required

### 🚀 How to Run

1. Download `library.py` from this repository.
2. Make sure Python 3.12 or newer is installed.
3. Open a terminal or command prompt in the folder containing the file.
4. Run the following command:

```bash
python library.py
```

*Depending on your operating system, you may need to use `python3 library.py` instead.*

Follow the on-screen prompts to start building your library!
